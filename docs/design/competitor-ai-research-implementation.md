## 七、有意的简化(demo 边界)

- **技能图谱/本体**:Workday Skills Cloud 级别的技能关系图不做,demo 用 JD skills 字段 + LLM 语义对齐即可。
- **真·多进程 Agent**:Workday 自己也用单入口编排;我们用可见步骤链 + 角色标签达成产品观感。
- **垂直行业模型**:大易 YonGPT 自训行业模型;我们用通用 LLM + 企业知识注入等价覆盖。
- **页面内文档编辑**:生成物可下载原生格式;页内编辑是未来增强项。

## 八、fallback 原则(「AI 挂了产品不瘫」)

- 无 embedding 配置/端点失败 → 自动退化纯 BM25,检索照常用(本轮已实测)。
- LLM 匹配失败 → 技能重叠度规则分;出题失败 → 回落预置题库。
- HF 免费额度耗尽(402)→ 同样降级,不阻塞知识库写入。

### 收敛范式

`多源数据 → 稳定能力维度 → 人级聚合 → 可解释熟练度(来源分解) → 分层呈现 → 决策建议`

### HROnfire 最小闭环落地

| 竞品要素 | 落地 | 状态 |
|---|---|---|
| 技能本体/图谱 | **有意不做**——数据密度撑不起;BM25+向量检索已覆盖召回侧 | skip |
| 稳定维度词库 | `match_gate.CRITERIA` 五维 + 评分卡自定义维度 + 技能档案字典,**按维度名归并** | ✅ |
| 多源算分(Workday skill level 模式) | `GET /api/talents/{id}/capability-profile`:match level(0-4→0-5 归一)/ 评分卡 score(1-5)/ CandidateSkill level(1-5) 三源聚合成人级 avg/min/max | ✅ |
| 来源分解(点开看分哪来的) | 每维度 `sources[]`:kind(match/interview/declared)+ 来源标签(岗位名/评分卡+面试官名)+ 证据/评语 + 时间 | ✅ |
| 显性+隐性双层 | `skills[]` = 声明技能 ∪ 候选人标签 ∪ 简历解析技能(显性);维度画像=评估推断(隐性) | ✅ |
| 分层呈现 | `TalentDetail`「能力画像」卡:雷达图(已有 RadarChart 复用)+ 优势▲/短板▽ 徽标 + 可下钻维度列表;个人层已完成,团队上卷留给人才盘点(已在人才地图有分布视角) | ✅ |

## 十二、AI 绩效助手四件套(北森 AI 绩效助手 / Moka 离职预警)

### 竞品实现要点(专项调研)

| 厂商 | 做法 |
|---|---|
| **北森 AI 绩效助手**(千金药业/德美化工案例) | 三段式:①AI 目标管理——输入岗位关键词→SMART 目标草稿→人工微调(采纳率 85%+);②AI 评价助手——自动抓取周期内关键事件与过程数据→结构化评价初稿(业绩达成+能力亮点+待改进),效率+60%;③AI 面谈助手——结构化话术建议+风险预警+面谈记录。另有 PIP 自动发起低绩效改进 |
| **Moka 离职预测** | 四层信号体系:L1 行为变化(活跃度降,提前4-6月)→ L2 绩效发展(评分下滑/晋升跳过)→ L3 考勤请假(请假激增/工时骤降,提前1-3月)→ L4 组织关系(1on1 断档/协作消失)。关键结论:**规则引擎多维信号评分在 200 人规模同样有效**;预警仅 HRBP 可见(关怀触发点而非监控名单);坑=把预警当管控、无干预流程 |
| **北森绩效分析** | 目标执行风险识别 + 历年趋势 + 绩效分布校准 |
| **大易** | 人岗画像结果回流优化(反馈进化≈我们决策学习) |

| 竞品要素 | 实现 | 状态 |
|---|---|---|
| 目标建议 | `POST /api/ai/goal-suggest`:员工岗位/部门/司龄+已确认技能+在途目标去重→LLM 产 SMART 目标(≤4条);LLM 不可用时岗位模板骨架降级;定目标弹窗「AI 建议目标」点击回填 | ✅ |
