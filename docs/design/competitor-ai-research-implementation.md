# 竞品调研 → HROnfire 实现方案对照

> 调研对象:Moka(Eva)、Workday(HiredScore)、北森(AI 面试官/AI 员工助手)、大易(用友 YonGPT 招聘)。
> 目的:对齐行业级做法,明确我们哪些已达成、哪些是有意简化、哪些是未来方向。
> 更新时间:随 P0-P3 + RAG 升级(A+C)交付后整理。

## 一、AI 编排与任务链

| 竞品做法 | 我们的实现 | 状态 |
|---|---|---|

## 七、有意的简化(demo 边界)

- **技能图谱/本体**:Workday Skills Cloud 级别的技能关系图不做,demo 用 JD skills 字段 + LLM 语义对齐即可。
- **真·多进程 Agent**:Workday 自己也用单入口编排;我们用可见步骤链 + 角色标签达成产品观感。
- **垂直行业模型**:大易 YonGPT 自训行业模型;我们用通用 LLM + 企业知识注入等价覆盖。
- **页面内文档编辑**:生成物可下载原生格式;页内编辑是未来增强项。

## 八、fallback 原则(「AI 挂了产品不瘫」)

- 无 embedding 配置/端点失败 → 自动退化纯 BM25,检索照常用(本轮已实测)。
- LLM 匹配失败 → 技能重叠度规则分;出题失败 → 回落预置题库。
- HF 免费额度耗尽(402)→ 同样降级,不阻塞知识库写入。
